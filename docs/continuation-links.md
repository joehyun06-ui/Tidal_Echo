# 已确认续窗关系读取

GET /app/sessions/{id}/continuation/links 经既有 relay 鉴权转发至 loop 对应只读接口。仅返回在创建记录与 canonical 续窗登记中一致、创建阶段已 registered 的关系；创建中、结果未知、登记不一致均不作为关系展示。不调用创建 factory、回执 reconcile、模型或记忆验证。

每次只读至最近 200 条登记关系，并用 partial 明确超过读取范围。仅保留同 provider 且双方当前仍可访问、未被停用或删除的会话。源版本仍存在且属于来源根会话时返回原版本，否则置 null，不暴露已删除版本标识，前端明确提示仅可查看来源当前版本。来源/目标、原版本与创建时间来自登记记录，不从会话标题推断。

返回不含 UUID、正文、摘要、HMAC、密钥或线程标识。未配置创建登记时 supported=false；无已确认关系与能力不可用分开。鉴权失败与存储错误不产生可确认的空统计。关系不代表消息已发出、模型收到、回复完成或记忆保留。

无新增表、迁移、生产参数或外部服务。复用现有会话归属锁、持久化账本与删除清理机制；读取双方关联时重新校验当前权限，不恢复已删除记录。全部验收使用临时 SQLite、合成数据与离线 Mock，真实模型请求保持禁用，v48、36/36、108/108 不变。
