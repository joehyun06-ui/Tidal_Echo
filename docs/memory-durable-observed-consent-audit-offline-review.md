# 归汀 · 观察到的浏览器确认事件持久审计（离线 Draft）

叠加 PR #144；**默认关闭、纯合成、无写入 HTTP、无真实认证/真人点击、无任何实际记忆保存**。独立模块 `backend/memory_durable_consent_audit.py` 以及 Linux/Windows unittest 验收。

## 审计结构

新建 `memory_consent_offer_audit_v1` 和 `memory_consent_event_audit_v1` 两张 SQLite 表，分别保存预览摘要及服务端“观察到”的 approve/decline 事件。表由 SQLite 触发器禁止 UPDATE、DELETE，事件每个 nonce 最多一次、事件引用唯一；预览及事件分别用**仅运行时提供、未持久化的 HMAC 密钥**签名。存储明文账号标识（合成样例）、不存记忆正文、不存原始 nonce、CSRF token、Origin、request_id 或事件引用；这些敏感字段只存 SHA-256 摘要。

准备与记录均在 `BEGIN IMMEDIATE` 持锁后取得可信服务器身份回调，比较 Origin/CSRF、当前会话、请求内容摘要，并在同一个事务中直接查验 SQLite 登录纪元的哈希与撤销状态。观察事件需要独立服务端 observer 回调，不能以客户端布尔值充当证据；这个 observer 在测试里是合成的，**因此即使写下 approve，也没有证明真人授权**。当前记录不能传给记忆保存 UOW 作为写入权限。

120 秒 TTL、跨进程复查签名/内容/时间顺序、一次性事件、冲突失败、独立实例争抢、登录撤销与纪元轮换、表不可变触发器都须离线验收。审计用于事后观察；撤销后旧历史仍可由具备审计密钥的内部只读进程核验，不授权新的保存操作。
